# Archivos fuente privados

Deja el PDF original de la ruta en esta carpeta con este nombre:

```text
private-assets/qr-route-source.pdf
```

Los PDF de esta carpeta estan ignorados por Git y nunca se sirven directamente
desde `public`. El archivo original solo se usa como referencia de tamano y
distribucion: puede conservar marcas antiguas que no deben llegar al comprador.

La aplicacion genera para cada compra un PDF nuevo con los 12 enlaces QR
personalizados. No copies este archivo a `public` ni lo incluyas manualmente en
la descarga.
